# Human playtest acceptance checklist

Automated fixtures do not complete this checklist. Record build SHA, seed, setup, result, observed friction, and reviewer initials for every session.

## Required matrix

Run each row in both singles and two-person tag, once with a typical roster and once with an equal high-END roster. Use the ordinary random-start control; export the replay after each match.

| Difficulty | Singles typical | Singles high-END | Tag typical | Tag high-END |
|---|---|---|---|---|
| Novice | ☐ | ☐ | ☐ | ☐ |
| Standard | ☐ | ☐ | ☐ | ☐ |
| Veteran | ☐ | ☐ | ☐ | ☐ |
| Ruthless | ☐ | ☐ | ☐ | ☐ |

For each match record: configured time limit; roster-strength relationship; finish method; elapsed match minutes; player/AI decision counts; pin/submission attempts; recoveries; hold releases/escapes; tags/interference; any unclear legal action; any empty/stalled decision; and whether pacing felt too short, acceptable, or too long. Verify the exported replay reproduces the final hash.

## Career acceptance

- [ ] Create random solo Career and random persistent-team Career.
- [ ] Schedule and complete singles and tag matches.
- [ ] Save/reload during an active match and complete it.
- [ ] Spend progression awards and confirm values after refresh.
- [ ] Advance across a month boundary; inspect ratings, title shots, obligations, injuries, and return eligibility.
- [ ] Export/import campaign and named-save bundle; compare preview and identity.
- [ ] Restore an autosave and reject an invalid/truncated import safely.
- [ ] Confirm optional extensions are off by default or explicitly labeled when enabled.
- [ ] Confirm ordinary player choices do not expose fixture-only roster controls unintentionally.
