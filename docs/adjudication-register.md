| M12-ADJ-07 | What is a fair salary? | The source defines no salary mechanics. | M12-ADJ-08 | How does popularity drive re-signing and acceptance? | The source defines no negotiation mechanics (see M12-ADJ-06). M12-ADJ-08 grades every offer against the wrestler's curve expectation: fair (≥ 100%) auto-accepts, low (< 60%) auto-rejects, short (60–100%) resolves on a recorded D20 whose accept threshold scales linearly (`floor((ratio − 60) / 40 × 20)`). On the first day a contract is inactive, the expiring wrestler is offered a renewal **at the expiring salary** and responds with the same rule, so a wrestler who outgrew their deal walks and the booker must offer up to the curve to keep them; accepted renewals keep the payout cadence unbroken. Only short offers consume the campaign's seeded RNG (recorded in the event dice), so the ledger replays byte-identically and extension-off campaigns hash exactly as before. | M12 negotiation design spec §4.2/§4.4; M12-ADJ-06 precedent | pinned seed-1991/2000 short-offer and renewal tests, cold/baseline/hot renewal walk tests | Implemented; human sign-off pending |
| M12-ADJ-09 | Should the campaign AI preemptively re-sign wrestlers whose popularity outgrew their salary? | M12-ADJ-08's renewal is offered at the expiring salary, so a wrestler who outgrew their deal (popularity up, salary flat) grades low and walks; the booker must notice and offer up to the curve manually. The bump lands exactly on the fair threshold, so it auto-accepts and consumes zero dice (the D20 sequence is untouched), and already-fair expiring salaries are offered unchanged — those renewals stay byte-identical to the default. `renewalStrategy` is absent (and byte-identical) when unset or "expiring-salary". | M12 negotiation design spec §4.5; M12-ADJ-08 precedent | curve-fair re-sign, short-bump zero-dice, already-fair identity, tamper-rejection tests | Implemented; human sign-off pending |

## Unresolved source contradictions

No M5 contradiction was found that required inventing a rule outside the manual plus audited GDD. The vacancy method is a configured deterministic implementation of discretion explicitly left to the championship committee; all other M5 entries apply direct text or audited adjudication. Independent review may still reopen any source transcription or interpretation. The M10-ADJ entries above record an explicit opt-in extension (the between-match injury check) because the source defines injuries only at match time, and M10-ADJ-04 records the re-scoped acceptance baseline for the M10 performance target (the tuned six-window ladder gate and the 301-test suite) after the empirical ladder tuning. The M11-ADJ entries record a GDD 18.2 revisit (cage/ladder rules). The M12-ADJ entries record a digital-only contracts-and-finance layer because the source defines no such subsystem at all; M12-ADJ-04 extends it so the tracked popularity stat mechanically gates title-shot eligibility and weights booking suggestions, and M12-ADJ-05 extends chemistry pairs from a popularity bonus into a monthly tag-rating bonus. The M13-ADJ entries record a digital-only feud-and-title-booking layer (rivalry heat, month-end booking cards, and a feud title-shot term) because the source defines feuds only as storyline flavor prose; all four entries stay opt-in and dice-free so the default campaign hashes byte-identically, and M13-ADJ-04 additionally rejects mixed-entrant feuds so the extension can never crash month-end booking. The M12-ADJ-06/07/08 entries record a contract-negotiation amendment to the M12 finance layer (offer/reject flows, a popularity salary curve, and popularity-driven expiry re-signing); the extension stays opt-in, short offers consume only a recorded seeded D20, and default campaigns hash byte-identically. M12-ADJ-09 extends that amendment with an opt-in campaign-AI renewal action (`renewalStrategy: "curve-fair"`) that matches the salary curve for outgrown expiring contracts, so hot wrestlers re-sign instead of walking — the bump is dice-free, and unset campaigns stay byte-identical.
